# gtgtdd-sys
Dave Life System reference and tools. “ultimately Good-enough Trying — getting there, despite Dave... System”. GTD based. Ne.ur0-∆i\/ friendly. 

uGTgtdD Sys

Also known as:
- DLS
- "you-git-gitted-Dave system"

uGTgtdD Sys is a lightweight, human-centered execution system for getting there despite imperfect conditions, executive-function friction, and the tendency for useful structures to become cathedrals before they have foundations.

This repo is a home for:
- the canonical one-page definition of the system
- naming and mode conventions
- principles and guardrails
- context documents
- project atoms
- potential tools and someday/maybe ideas

- `docs/` — stable definitions
- `ideas/` — tool ideas and someday/maybe items
- `project_atoms/` — smallest useful project units
- `tools/` — actual implementations and prototypes
- `context_docs/` — portable setup docs for focused work
