# Potential Tools

This file collects possible tools for uGTgtdD Sys. Presence here does not mean “build now.” It means “worth remembering, naming, and evaluating.”

## Rule
Search for existing implementations before building new ones.

## Current High-Interest Ideas

### 1. MOOC syllabus -> ADHD-friendly flexible syllabus
A tool to translate a rigid course outline into a more flexible, executive-function-aware structure.

Possible features:
- chunking
- fallback plans
- flexible pacing
- visible minimum viable progress
- “good enough for today” views

### 2. Prioritization toolkit
A family of prioritization methods ranging from quick-and-reckless to more thorough.

Possible methods:
- pairwise comparison
- top-N selection
- most/least/middle prompts
- elimination prompts
- Eisenhower grouping
- bracket-style tournament selection
- partial-ranking refinement
- urgency overlays
- consensus/group simulation
- repeated-self voting across days/weeks

## Notes
- The goal is not to build every method.
- The goal is to identify useful methods, find existing implementations where possible, and build only where needed.
